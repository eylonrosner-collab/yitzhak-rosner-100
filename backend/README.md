# ספר זיכרונות – הפעלה ועדכון

## הפעלה ראשונה (פעם אחת, כ־5 דקות)

1. פתחו את הגיליון "יצחק רוזנר 100 – ספר זיכרונות" ב־Google Drive שלכם.
2. בתפריט: **הרחבות ← Apps Script** (Extensions → Apps Script).
3. מחקו את מה שיש בעורך, הדביקו את כל התוכן של `Code.gs` ושמרו.
4. בחרו בפונקציה `setup` ולחצו **Run** (הפעלה). Google יבקש הרשאות (Sheets, Drive ושליחת מייל אליכם). אשרו. אם מופיע "Google hasn't verified this app", לחצו Advanced ואז Go to project. זה הסקריפט שלכם, בחשבון שלכם.
5. **Deploy ← New deployment**, סוג: **Web app**.
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Deploy. העתיקו את כתובת ה־Web app (מסתיימת ב־`/exec`).
6. שלחו לבוט את הכתובת, והוא יכניס אותה לקובץ `config.js` באתר.

## עדכון סקריפט קיים (אותו URL)

1. פתחו את פרויקט ה־Apps Script של הגיליון, החליפו את `Code.gs` בגרסה החדשה ושמרו.
2. **Deploy ← Manage deployments** ← העיפרון של ה-deployment הקיים ← **New version** ← Deploy. אותו URL נשאר.
3. הרצת `setup` מחדש **אינה חובה**: בבקשת list או שליחה ראשונה אחרי הפריסה, `ensureSchema_()` תוסיף לבד את העמודות החסרות (`hidden`, `id`, `edit_token`, `edited_at`) בלי למחוק נתונים. מומלץ בכל זאת להריץ את `setup` פעם אחת כדי שעמודת `hidden` תקבל תיבות סימון מסודרות גם בשורות הקיימות.

## איך זה עובד עכשיו

- כל זיכרון חדש מתפרסם באתר מיד. אין צורך לסמן `approved`.
- העמודה `approved` נשארת בגיליון לתאימות לאחור, והאתר מתעלם ממנה.
- כדי להסתיר זיכרון מהאתר: סמנו V בעמודה `hidden`, או מחקו את השורה.
- קבצים נשמרים בתיקייה "יצחק רוזנר 100 – קבצים מהאתר" ומשותפים כ-Anyone with the link (צפייה), כדי שהמבקרים יוכלו לראות תמונות באתר.
- כל שורה מקבלת `id` ו-`edit_token` סודי. הטוקן לא מוחזר ב-list; מי ששלח מהדפדפן יכול לערוך את הזיכרון מאותו מכשיר. אפשר תמיד לערוך ישירות בגיליון.
- אחרי עריכה באתר מתעדכן `edited_at`, ובאתר מופיע "(נערך)".
